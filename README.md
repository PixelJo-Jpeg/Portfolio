# Jowel Tamondong — Portfolio

Personal portfolio site for Jowel Tamondong, graphic designer.

## Live site

Published via GitHub Pages: `https://<your-username>.github.io/jowel-portfolio-site/`

## What's here

```
index.html    the entire site — markup, styles, and data in one file
```

No build step, no dependencies, no framework. Open `index.html` and it runs.

## Structure

- **Hero** — headline, meta grid, and a layered brand-element composition
- **Work** — all 12 Behance projects, each linking to its own case study
- **Filters** — category buttons built from the categories actually present
- **About** — copy and a details table
- **Contact** — email and Behance calls to action

## Images

Project covers are hotlinked from Behance's CDN at 808px:

```
https://mir-s3-cdn-cf.behance.net/projects/808/<hash>
```

So swapping a cover on Behance updates the site automatically, and the repo
stays small (~20 KB). Nothing is stored in git.
